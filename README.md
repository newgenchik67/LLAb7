# Домашнее задание к работе 7
## Условие задачи (30 Вариант)
Составьте программу, определяющую название ноты по ее номеру: 1 –
До, 2 – Ре и т.д. При вводе числа вне диапазона от 1 до 7 программа должна
выдать сообщение об ошибке.
## 1. Алгоритм и блок схема
### Алгоритм
1. Начало
2. Задать константы: соответствие номеров нот и их названий ( реализовано при помощи ```case``` оператора ```switch```: 1 - «До», 2 - «Ре», 3 - «Ми», 4 - «Фа», 5 - «Соль», 6 - «Ля», 7 - «Си»).
3. Запросить у пользователя номер ноты ```c```(целое число от 1 до 7).
4. Проверить значение c с помощью оператора switch (c):
- если ```c == 1 ```— вывести «До»;
- если ```c == 2 ```— вывести «Ре»;
- если ```c == 3``` — вывести «Ми»;
- если ```c == 4``` — вывести «Фа»;
- если ```c == 5``` — вывести «Соль»;
- если ```c == 6``` — вывести «Ля»;
- если ```c == 7``` — вывести «Си».
5. Если значение ```c``` не соответствует ни одному из допустимых номеров (1–7), выполнить блок ```default``` и вывести сообщение «Ошибка».
6. Завершить программу.
